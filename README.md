# Blender Extensions

Extensions for Blender 4.2 and newer.

## Add-ons

| Add-on | Description | Min. Blender |
|--------|-------------|:------------:|
| Multi Range Renderer | Render multiple frame ranges with selected cameras | 4.2 |
| LayerCake | Rebuild the Combined image from render passes | 4.2 |
| Patchwork | Multi-pattern anti-tiling for image textures (Voronoi / Noise / Gabor / Blocks / Rings) | 5.0 |
| EXReplace | Swap Render Layer and multilayer EXR connections in the Compositor | 4.5 |
| CopyRender | Copy and paste render settings via clipboard | 4.2 |
| Listen, Children! | Sync visibility between parent and child objects | 4.2 |

## Install in Blender

Add the repository so the add-ons install and update from inside Blender:

1. **Edit → Preferences → Get Extensions**.
2. Dropdown (⌄) → **Repositories** → **＋** → **Add Remote Repository**.
3. Paste this URL:

   ```
   https://raw.githubusercontent.com/kunemann/blender-extensions/main/docs/index.json
   ```

4. Open **Get Extensions** and install any add-on from the list above.

Or drag an add-on's `.zip` into a running Blender 4.2+ window to install it directly.
